# CHIMES 0.3.0 — Schooling and interactive exploration

CHIMES 0.3.0 expands collective-movement models and makes interactive exploration, individual variation and reproducible experiments easier to use.

## Highlights

- Explicit 2D Couzin, overlapping-zone, Vicsek, Boids and Voronoi-filtered movement models, with controls appropriate to each model and documented assumptions.
- One simple Boids schooling model with separation, alignment and cohesion, independent minimum/maximum speeds, faint perception circles and a ready-to-load schooling example.
- Off/Repel/Attract cursor interaction, editable numeric slider fields and an optional individual-variation editor.
- Distinct type colours and working custom colour pickers, with matching headings and explicit trait/position colour modes.
- Largest-group polarisation/cohesion in Information, background position analysis and individual mean-position views that exclude unavailable samples.
- Shared scenario settings, condition grids, a separate experiment GUI, streaming output, performance reports and analysis/plotting helpers.
- Improvements to recording, drawn walls, perception overlays, window persistence and GUI shutdown.

## Upgrading and interpreting results

- Use `chimesim.settings()`, `chimesim.interactive()` and `chimesim.simulate()`. Replace older `run()` calls with `interactive()`; advanced classes are imported from their internal modules rather than the package root.
- **Boids trajectories change in this release.** Existing settings remain loadable, but the same seed does not reproduce older Boids trajectories. Minimum speed defaults to zero; the schooling example explicitly sets a positive minimum. Legacy separation-radius and acceleration-limit fields no longer affect Boids.
- Information polarisation and cohesion now describe the largest spatial group. Offline whole-type `metrics.compute()` summaries keep their documented meaning.
- These are documented planar adaptations, not complete reproductions of the original three-dimensional models. Environmental and cursor interactions are explicit extensions.

## Getting started

Install the attached wheel with `python -m pip install chimesim-0.3.0-py3-none-any.whl`, or install from the tagged source with `python -m pip install "git+https://github.com/JolleJolles/CHIMES.git@v0.3.0"` after the release is published.

Tkinter is required for the interactive interface. Python 3.9 remains the declared minimum; see the compatibility guide for platform details. No PyPI publication is implied by this GitHub release.

Start the interface with:

```python
import chimesim
chimesim.interactive()
```

Load `examples/boids_schooling.json` from the source checkout for a schooling starting configuration.

The full detailed changes are in [CHANGELOG.md](https://github.com/JolleJolles/CHIMES/blob/v0.3.0/CHANGELOG.md), with usage and model assumptions under `docs/`.
